description=[h2]✨ What is this[/h2]
description=Overlays a map image rendered from actual in-game visuals directly onto the B42
description=in-game world map, replacing the vanilla vector-line style. Built on the B42
description=engine's native ImagePyramid mechanism:
description=[list]
description=[*] Multi-level LOD — smooth zooming, no more stutter
description=[*] Engine-level texture caching and async loading — low VRAM usage
description=[*] What you see is what you get: buildings, roads and vegetation match the in-game look
description=[/list]
description=
description=[h2]🧰 Features[/h2]
description=[list]
description=[*] [b]Image-based world map & corner mini-map[/b] — buildings, roads and vegetation match the in-game look; prefer vanilla? One toggle falls back to the vector style while every other feature keeps working
description=[*] [b]Mini-map hotkey[/b]: / (slash, right of M) by default (rebindable); works even when the server sandbox disables the mini-map; installs still on the old HOME default are auto-migrated to / on first game start
description=[*] [b]Floating toggle icon[/b]: an always-on-screen mini icon that toggles the mini-map on click — no hotkey needed; drag to reposition, position remembered, hover shows the current hotkey (can be disabled in settings)
description=[*] [b]Flexible sizing[/b]: four presets + free resize by dragging the mini-map edges, remembered automatically
description=[*] [b]Always-visible button bar[/b]: no more hover-expanding; gear button opens the unified settings window — two-column collapsible sections with expand/collapse all (no ESC menu needed)
description=[*] [b]Navigation targets[/b]: right-click the map to set a target — flag + edge direction arrow + distance, auto-clears on arrival; share to your faction with one click
description=[*] [b]Live zombie dots[/b] (off by default): real-time zombie positions with adjustable color / size / opacity / cap
description=[*] [b]Zombie heatmap[/b] toggle (off by default)
description=[*] [b]Animal icons[/b] (off by default): live nearby animals — separate wild/livestock toggles and 9 built-in species filters; the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3765182411]third-party MOD compatibility pack[/url] adds supported species such as dogs and horses; map-symbol or colored item-icon style, adjustable size, opacity and color (colorblind-friendly 8-color palette)
description=[*] [b]Vehicle icons[/b] (off by default): steering-wheel markers for nearby vehicles; standard / heavy-duty / sports / emergency (lightbar) category filters, adjustable size, opacity and color
description=[*] [b]World map icons[/b]: zombie / animal / vehicle icons on the world map (M) too — four separate toggles; style, colors and filters follow your mini-map settings; a new paw button on the world map opens the settings window directly
description=[*] [b]Street names[/b]: on the corner mini-map too (vanilla only shows them on the world map)
description=[*] [b]Safehouse outlines[/b]: yours in green, others in red
description=[*] [b]Free look[/b]: drag to pan and stay, click once to snap back to the player; a recenter hint appears while panned away (like navigation apps)
description=[*] [b]Server sandbox controls[/b]: disable zombie dots / heatmap / animal / vehicle icons; limit zombie / animal / vehicle / safehouse-outline display distance; configure safehouse display, four livestock visibility modes and faction sharing — admin changes apply live
description=[*] [b]Singleplayer & multiplayer[/b]: works out of the box in SP; in MP the server enables the mod (PZ servers dictate the mod list — players can't sideload it), and admins stay in control via the sandbox options above — the mod only visualizes data the client already receives, no extra intel
description=[*] [b]Languages[/b]: Traditional Chinese / Simplified Chinese / English / Japanese
description=[/list]
description=
description=[b]⚠️ Note for -debug users[/b]: HOME is a hidden engine render-debug key — pressing it switches the world render path (roughly half the FPS, snow visuals change), and it fires alongside anything bound to HOME. This mod now defaults to / (slash) and auto-migrates old installs; if your toggle is still on HOME, please rebind. In game, the mini-map shows an orange warning bar whenever a binding conflict or the legacy render path is detected, with instructions to recover.
description=
description=[h2]🧩 Map MOD support[/h2]
description=Pair it with the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763914102]Minidoracat MiniMap - MOD Maps[/url] map pack addon: it ships
description=mini-map images and area outlines (with names, multi-language) for several map
description=MODs, [u]auto-detected[/u] — a map's image only shows when that map MOD is
description=enabled, so nothing is drawn for maps you don't have. Installing the map pack
description=also unlocks extra options (MOD map tiles toggle, outline toggle, outline color, outline opacity).
description=Map MOD authors can also ship their own support: render your map into a file
description=named [b]minidoracat_minimap.pyramid.zip[/b] and put it in [b]media/minimap/[/b] —
description=[u]no Lua required[/u]. This MOD auto-detects and overlays it (auto-aligned,
description=drawn above the base map).
description=
description=[h2]🗺️ Built-in resource points (POI, 0.8.0+) + Zone layer API (0.7.0+)[/h2]
description=[b]Resource points ship with the mod[/b]: 499 built-in vanilla-map resource points across
description=14 categories (military, police, gun store, medical, pharmacy, fire, library, school,
description=grocery, gas, tools, outdoor, prison, storage — each with a distinct color). The
description=default "icon mode" draws a tinted silhouette icon at every point (no label clutter), with
description=an optional full-color icon style, with size and opacity sliders; an optional "Show resource blocks" adds translucent
description=blocks and names, and every category can be toggled in the "Resource point icons" section of
description=the unified settings window (each row shows its category icon; plus a quick toggle in
description=the gear panel). [u]Resource-point data is extracted directly from the official vanilla
description=map files[/u] (not hand-placed) — if a point looks wrong or misclassified, the official
description=data itself is wrong; it will be corrected once the game fixes its data and this mod
description=syncs with the update. This MOD also provides a zone-rendering framework:
description=`registerZoneProvider(ownerModId, providerFn, optionLabelKey)` lets addons supply rectangle
description=zone data while this MOD draws semi-transparent fills, outlines, centered names and icons on
description=both the mini-map and world map; passing optionLabelKey grants a dedicated per-provider
description=toggle. Pair it with the zone-display addon [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3768276209]Minidoracat MiniMap Zones[/url]
description=(Mod ID: MinidoracatMiniMapZonesFor42) to additionally show server-defined zones (a
description=`zones.json` writable by external tools). Without the addon, this MOD's other features are
description=unaffected.
description=
